# createawebsite.ca

A done-for-you website at a fixed price, run by Monkeys at Work. Visitors answer a few questions, preview a site
assembled from a section kit, and ask us to build it; the team delivers in 10 business days.

Start with `CLAUDE.md`, then `docs/configurator-brief.md` (the spec), then `docs/DECISIONS.md`. Setup and commands
arrive with phase 1 of the brief.

The earlier quote-first lander that lived here is in git history at commit `3dcc7f6` on branch
`claude/new-session-dpotje`.
